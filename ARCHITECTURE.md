# Технические решения и границы анализа

## Роли инструментов

- Trivy формирует CycloneDX SBOM из выбранного набора зависимостей.
- CycloneDX описывает состав ПО в машиночитаемом формате. Сам по себе SBOM не подтверждает отсутствие уязвимостей.
- pip-audit проверяет зафиксированные Python-зависимости; его JSON-результаты используются для отчётов и сравнения состояний.
- Dependency-Track предназначен для учёта компонентов и обработки результатов анализа. Для него подготовлены Docker Compose и скрипт загрузки SBOM через REST API.
- Trivy Server предусмотрен как внешний анализатор Dependency-Track. Сквозной запуск этой интеграции пока не подтверждён.

## Почему сохранены два состояния

Наборы `before` и `after` позволяют проверить не только обнаружение проблем, но и результат изменения версий. Намеренно устаревшие зависимости анализируются как входные данные: приложение с ними не запускается. Отчёт сопоставляет число проверенных компонентов, затронутые компоненты и уникальные идентификаторы находок.

## Контроль в CI

GitHub Actions генерирует SBOM, выполняет аудит, формирует отчёты и сохраняет артефакты. Для обновлённого набора включён `FAIL_ON_FINDINGS=1`: известные уязвимости приводят к ошибке проверки. Это контроль данного workflow, а не утверждение о настроенной блокировке релизов или защищённой ветке.

## Интерпретация результата

- CVE, GHSA и PYSEC могут быть алиасами одной уязвимости. Количество идентификаторов не равно количеству независимых уязвимостей.
- Наличие уязвимого компонента не доказывает эксплуатируемость: нужны сведения о коде, доступных функциях и окружении.
- CVSS помогает оценить техническую критичность, но приоритет исправления также зависит от доступности компонента извне, значимости системы и наличия исправлений.
- Обновление версии требует проверки совместимости. Этот проект не заменяет функциональное тестирование приложения.
- Отсутствие известных находок относится к конкретному набору прямых зависимостей и данным на дату сканирования. Транзитивные зависимости и рабочее окружение требуют отдельной оценки.
